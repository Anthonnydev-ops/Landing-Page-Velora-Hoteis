# 🏨 Velora Hotels & Resorts

Uma landing page moderna e elegante para divulgação de hotéis e resorts de luxo, desenvolvida com foco em experiência visual, responsividade e interação do usuário.

O projeto apresenta destinos exclusivos, acomodações premium, avaliações de clientes e um formulário de reserva com validações dinâmicas, proporcionando uma experiência sofisticada para visitantes interessados em viagens de alto padrão.

---

## ✨ Funcionalidades

* 🏝️ Apresentação de destinos turísticos exclusivos
* 🏨 Seção de acomodações e experiências premium
* ⭐ Avaliações e depoimentos de hóspedes
* 📊 Estatísticas destacando números da empresa
* 📅 Formulário de reserva com validação de datas
* 🔔 Notificações visuais (Toast Notification)
* 🎨 Design moderno e sofisticado
* 📱 Layout totalmente responsivo
* ⚡ Animações suaves durante a navegação
* 👀 Efeito Scroll Reveal utilizando Intersection Observer

---

## 🛠️ Tecnologias Utilizadas

* HTML5
* CSS3
* JavaScript (Vanilla JS)
* Google Fonts
* Intersection Observer API

## 🚀 Como Executar

1. Clone o repositório:

```bash
https://github.com/Anthonnydev-ops/Landing-Page-Velora-Hoteis.git
```

2. Entre na pasta do projeto:

```bash
cd velora-hotels
```

3. Abra o arquivo `index.html` no navegador. Ou entre no link `https://landing-page-velora-hoteis.vercel.app/`
