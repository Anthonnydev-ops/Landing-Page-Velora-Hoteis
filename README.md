# 🏨 Velora Hotels - Luxury Landing Page

Uma landing page premium e responsiva desenvolvida para o fictício **Velora Hotels**, um hotel de luxo 5 estrelas. O projeto combina um design minimalista, tipografia sofisticada e interações fluidas para proporcionar uma experiência de usuário (UX) imersiva e sofisticada.

---

## ✨ Funcionalidades

*   **Design Visual Premium:** Uso de paleta de cores sóbrias com detalhes em dourado (`--gold`) e combinação tipográfica elegante (*Cormorant Garamond* e *Jost*).
*   **Scroll Reveal Inteligente:** Elementos da página surgem suavemente conforme o usuário navega, utilizando a API nativa `IntersectionObserver` do JavaScript para alta performance.
*   **Navegação Dinâmica:** O menu de navegação (`<nav>`) adapta sua opacidade e ganha sombra ao rolar a página, garantindo legibilidade contínua.
*   **Formulário de Reserva Inteligente:** 
    *   Bloqueio de datas passadas no campo de Check-in.
    *   Atualização dinâmica do Check-out para impedir que a data de saída seja anterior à de entrada.
*   **Toast Notifications Customizados:** Feedback de envio de formulário com uma notificação flutuante elegante, substituindo os alertas nativos do navegador.

---

## 🚀 Tecnologias Utilizadas

O projeto foi construído puramente com tecnologias web nativas, prezando pela performance e sem a necessidade de frameworks pesados:

*   **HTML5:** Estruturação semântica e acessível.
*   **CSS3:** Estilização avançada utilizando Variáveis CSS (Custom Properties), Flexbox e CSS Grid para total responsividade.
*   **JavaScript (ES6+):** Manipulação de DOM, validações lógicas e animações baseadas em rolagem (`IntersectionObserver`).
